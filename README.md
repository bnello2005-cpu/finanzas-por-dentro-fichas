# Finanzas por dentro · Fichas de los casos

Cada vídeo de **Finanzas por dentro** explica un caso real del mundo financiero: compras apalancadas (LBO), quiebras, salidas
a bolsa, reestructuraciones y fondos. Esta es la ficha de cada caso, en PDF de una página:

- **Qué pasó**, en cuatro o cinco frases.
- **Las cifras clave.**
- **El cálculo, paso a paso** (por ejemplo, cuánto pusieron los compradores y cuánto fue deuda).
- **Las fuentes.** Cada dato se ha comprobado con dos fuentes independientes, y las cuentas se han hecho con código.
